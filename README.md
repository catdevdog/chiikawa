# Desktop Buddy

바탕화면을 돌아다니고, 마우스에 붙어 다니고, 마우스에 반응하는 **Windows 데스크탑 펫**이에요.
(Desktop Buddy는 가칭입니다. A tiny desktop pet for Windows that wanders the screen, sticks to your mouse and reacts to it.)

## 다운로드와 설치 (Windows 10 / 11, 64비트)

1. 위의 **설치 파일(.exe)** 버튼을 눌러 받아요. 설치가 싫으면 **포터블 zip**을 받아서 풀고 `Desktop Buddy.exe`를 실행하세요.
2. 설치 파일을 실행하면 바로 설치되고 시작돼요.
3. 처음 실행할 때 Windows가 "PC를 보호했습니다" 화면을 띄울 수 있어요. 코드 서명을 안 한 앱이라서 그래요. **추가 정보 → 실행**을 누르면 돼요.
4. 펫은 주 모니터에서 시작하고, 작업 표시줄 오른쪽 아래(숨겨진 아이콘 `^` 안일 수 있어요)에 트레이 아이콘이 생겨요.

버튼이 안 열리거나 릴리스보다 새 빌드를 받고 싶으면 [Actions](https://github.com/catdevdog/chiikawa/actions/workflows/build.yml)에서 초록 체크가 붙은 맨 위 항목을 열고, 맨 아래 **Artifacts**의 `windows`를 받으세요. zip 안에 설치 파일과 포터블 zip이 들어 있어요. GitHub 로그인이 필요하고 90일 뒤에 지워져요.

## 지금까지 된 것

- Windows 데스크탑 펫 앱 (Electron). 투명한 창 위에 펫이 돌아다니고, 펫이 없는 곳은 클릭이 그대로 통과해요.
- 모드 4가지(자동, 따라가기, 마우스에 붙어있기, 배회)와 마우스 반응(올리기, 클릭, 세 번 클릭, 쓰다듬기, 드래그, 던지기, 도망, 졸기).
- 캐릭터는 우사기, 하치와레, 치이카와, 랏코와 스프라우트(직접 만든 마스코트) 다섯 개예요. 메뉴에는 한글 이름으로 보여요. 처음 설치하면 우사기로 시작해요. 눈을 깜빡이고 잘 때는 눈을 감아요. 귀와 꼬리가 있는 캐릭터는 걸을 때 흔들려요.
- 스킨 메이커: 이미지를 끌어다 놓고 포즈만 고르면 스킨이 만들어져요. 배경 지우기, 좌우 반전, 크기 맞추기, 미리보기가 있어요.
- 정지 그림에 움직임 넣기: 그림에서 눈, 귀, 꼬리를 찾아서 눈 깜빡임과 귀·꼬리 흔들림을 만들어요. 그림을 새로 그리지 않고 원래 픽셀을 살짝 변형해요.
- 모니터가 여러 대면 펫이 모니터 사이를 걸어 다녀요. 경계에 걸쳐 서 있으면 양쪽 모니터에 나뉘어 그려지고, 모니터마다 바닥 높이가 다르면(작업 표시줄이나 해상도 차이) 계단처럼 오르내려요. 모니터를 뽑거나 꽂거나 해상도를 바꿔도 따라가요.
- 대사: 펫이 상황마다 한마디씩 해요. 말풍선 없이 z나 하트처럼 그려져서, 짧은 소리는 위로 떠올랐다 사라지고 문장은 머리 위에 잠깐 떠 있다 사라져요. 모든 캐릭터에 그 캐릭터 말투의 대사가 들어 있어요.
- 자동 업데이트: 설치 파일로 설치한 앱은 실행하고 30초 뒤, 그리고 6시간마다 새 버전이 있는지 보고, 있으면 백그라운드로 받아 둬요. 다 받으면 알림이 뜨고 트레이 메뉴에 **vX 설치하고 다시 시작**이 생겨요. 누르지 않아도 앱을 종료할 때 설치돼요. 포터블 zip은 스스로 업데이트하지 못해서, 메뉴의 **새 버전 확인**이 릴리스 페이지를 열어줘요. 확인할 때 접속하는 곳은 github.com뿐이고, 지금 버전은 트레이 아이콘에 마우스를 올리면 보여요.
- 재롱(특별 행동): 캐릭터마다 가끔 특별한 행동을 해요. 하치와레는 사진을 찍고 손을 비비며 조르고, 치이카와는 빗자루질을 하고 잠옷 차림으로 하품하고, 우사기는 훌라춤을 추고 응원 도구를 흔들고, 스프라우트는 손을 흔들고 간식을 먹어요. 트레이 메뉴의 **재롱 부리기**로 바로 볼 수 있고, 잠금 해제·충전기·배터리 부족 같은 때에는 그 상황에 맞는 재롱으로 반응해요.
- 펫 부르기와 잠깐 숨기기: 어느 프로그램을 쓰고 있어도 `Ctrl + Alt + Shift + C`로 부르면 마우스 옆으로 달려오고(아주 멀면 위에서 떨어져요), `Ctrl + Alt + Shift + H`로 숨기고 다시 불러낼 수 있어요. 숨겨진 동안은 움직이지도 클릭을 막지도 않아요.
- 친구들: 트레이 메뉴의 **친구들**에서 다른 캐릭터를 골라 함께 지낼 수 있어요(최대 4명, 모두 다섯 마리까지). 친구는 마우스와 상관없이 혼자 돌아다니고, 가끔 다른 친구 곁으로 가서 서로 인사해요. 치이카와·하치와레·우사기·랏코는 서로를 부르는 말투가 따로 있어요(예: 하치와레가 "랏코 씨~! 안녕하세요!"). 부르기·숨기기·컴퓨터 소식은 모두에게 똑같이 적용돼요.
- 컴퓨터에 반응: 화면 잠금을 풀거나 절전에서 깨어나면 반기고, 충전기를 꽂거나 빼면 알아채고, 배터리가 20% 아래로 떨어지면 알려줘요.
- 바뀐 점 알림: 업데이트한 뒤 처음 켜면 무엇이 바뀌었는지 알림으로 알려줘요. 트레이 메뉴의 **바뀐 점 보기**에서 언제든 볼 수 있고, 전체 목록은 [CHANGELOG.md](CHANGELOG.md)에 있어요.
- 트레이 메뉴에서 크기, 이동 범위, 모니터, 대사, 캐릭터, 친구들, 클릭 통과, 시작 시 실행, 업데이트 자동 확인을 바꿀 수 있어요.

## 아직 안 된 것

- 스킨 메이커와 우사기·하치와레·치이카와·랏코 스킨은 Windows에서 아직 확인 전이에요. 개발 환경이 Linux라서 이 부분은 Linux에서만 테스트했어요.
- 컴퓨터에 반응하는 기능(잠금 해제, 절전 복귀, 충전기, 배터리 부족)과 전역 단축키는 Linux에서 가짜 이벤트로만 시험했어요. 실제 Windows에서는 아직 확인 전이에요.
- 친구들(여러 마리)도 Linux에서만 시험했어요. 실제 Windows에서 다섯 마리가 함께 있을 때의 부하와 겹쳐 있을 때의 클릭은 아직 확인 전이에요.
- 걷기는 따로 그린 그림이 아니라 기본 그림을 움직여서 만든 거예요. 다리가 실제로 움직이는 걷기는 아니에요. 그림이 없는 포즈(예: 치이카와의 달리기·앉기)는 비슷한 포즈 그림을 대신 써요.
- 멀티 모니터는 Linux에서 가짜 모니터로만 시험했어요. 실제 Windows 모니터, 특히 배율이 서로 다른 모니터(예: 100%와 150%) 사이는 아직 확인 전이에요.
- 대사는 한국어뿐이에요. 스킨 메이커에서 대사를 넣는 기능은 아직 없어요(manifest.json에 직접 적어요).
- 설정창과 소리는 아직 없어요.
- 전체화면 앱 위에서 숨기는 기능이 없어요.
- 자동 업데이트는 Linux에서 가짜 업데이트 서버로만 시험했어요. Windows에서 실제로 설치까지 되는지는 0.3.1을 설치한 뒤 다음 버전이 나와야 확인돼요. 업데이트 기능이 들어가기 전 버전(0.3.0 이하)을 쓰는 분은 0.3.1을 한 번 직접 설치해야 해요.
- 코드 서명이 없어서 처음 실행할 때 Windows 경고가 떠요. 업데이트 파일도 서명이 아니라 GitHub 릴리스에 적힌 체크섬으로만 확인해요.
- 만드는 건 Windows용뿐이에요. macOS와 Linux용 빌드는 없어요.

## 사용법

트레이 아이콘을 클릭(또는 우클릭)하면 메뉴가 열려요.

| 메뉴 | 설명 |
|---|---|
| 펫 부르기 | 펫이 마우스 옆으로 와서 인사해요. 자고 있어도, 숨어 있어도 와요. 단축키 `Ctrl + Alt + Shift + C` |
| 잠깐 숨기기 | 펫을 치워 둬요. 다시 누르면(**다시 나타나기**) 그 자리에서 돌아와요. 단축키 `Ctrl + Alt + Shift + H` |
| 재롱 부리기 | 캐릭터가 재롱을 하나 보여줘요. 재롱이 있는 캐릭터에서만 보이고, 펫이 숨어 있을 때는 누를 수 없어요 |
| 모드 | **자동**(마우스가 움직이면 따라오고, 멈추면 돌아다니다 졸아요) · **따라가기** · **마우스에 붙어있기** · **배회** |
| 크기 | 작게 / 보통 / 크게 / 아주 크게 |
| 이동 범위 | **화면 전체** 또는 **바닥만** |
| 모니터 | **모든 모니터**(기본) · **주 모니터만** · 모니터 하나 고르기. 모니터가 한 대면 이 메뉴는 보이지 않아요 |
| 대사 | **반응과 혼잣말**(기본) · **반응할 때만** · **끄기** |
| 캐릭터(스킨) | 설치된 스킨 선택, **스킨 폴더 열기** |
| 친구들 | 함께 지낼 다른 캐릭터를 골라요(체크하면 바로 나타나고 빼면 사라져요). 최대 4명까지고, 고를 다른 캐릭터가 없으면 이 메뉴는 보이지 않아요 |
| 스킨 만들기… | 이미지로 직접 스킨을 만드는 **스킨 메이커**를 열어요 (배경 지우기 포함, 아래 설명) |
| 방해하지 않기 | 켜면 펫이 클릭을 전혀 가로채지 않아요 (움직이기만 해요) |
| Windows 시작 시 실행 | 설치 버전에서 동작해요 |
| 업데이트 자동 확인 | 설치 버전에서만 보여요. 끄면 백그라운드 확인과 다운로드를 멈춰요(아래 **업데이트 확인**은 그대로 써요) |
| 업데이트 확인 | 지금 새 버전을 찾아요. 찾으면 받아 두고, 다 받으면 **vX 설치하고 다시 시작**으로 바뀌어요. 포터블 zip에서는 릴리스 페이지를 열어요 |
| 바뀐 점 보기 | 지금 버전에서 무엇이 바뀌었는지 릴리스 페이지를 열어요 |
| 종료 | 비상 종료 단축키: `Ctrl + Alt + Shift + B`. 받아 둔 업데이트가 있으면 종료할 때 설치돼요 |

**펫과 놀기**

- 마우스를 올리면 걸음을 멈추고 쳐다봐요. 좌우로 문지르면(쓰다듬기) 좋아해요.
- 클릭하면 깜짝 놀라요. 빠르게 3번 클릭하면 기뻐해요.
- 잡아서 끌면 들려서 대롱대롱 매달리고, 놓으면 떨어져요. 휙 던질 수도 있어요.
- 마우스를 빠르게 휘둘러 다가가면 놀라서 도망가요(배회 중일 때).
- 아무도 건드리지 않으면 졸다가 잠들어요.
- `Ctrl + Alt + Shift + C`(또는 메뉴의 **펫 부르기**)로 부르면 어디에 있든 마우스 옆으로 와요. 가까우면 달려오고, 아주 멀거나 다른 모니터에 있으면 마우스 위에서 떨어져요.
- 자리로 돌아오면(화면 잠금 해제, 절전에서 깨어남) 반기고, 충전기를 꽂고 뺄 때나 배터리가 얼마 안 남았을 때도 한마디 해요.
- **붙어있기** 모드에서는 펫이 마우스 커서에 매달려 따라와요. 이때 펫은 클릭을 가로채지 않아서 평소처럼 작업할 수 있어요.
- 클릭, 쓰다듬기, 들어 올리기, 던지기, 잠들기와 깨기, 다른 모니터로 건너가기 같은 때에 한마디씩 해요. 가만히 두면 가끔 혼잣말도 해요.
- 가만히 돌아다니다가 가끔 재롱을 부려요. 부리는 동안에는 제자리에 있고, 클릭하거나 잡으면 바로 멈춰요. 자동 모드에서 마우스를 움직여 멀리 가면 재롱을 그만두고 따라와요.
- 친구가 있으면 서로 가까이 만났을 때 먼저 다가간 쪽이 인사하고, 잠깐 뒤에 상대가 대답해요. 같은 둘은 한동안 다시 인사하지 않아요. 겹쳐 있으면 화면에서 더 아래에 있는(앞에 보이는) 펫이 클릭을 받고, 친구도 똑같이 쓰다듬고 들어 올리고 던질 수 있어요. **마우스를 따라가거나 붙어있는 건 처음 고른 캐릭터뿐**이고 친구는 늘 배회해요.

## 캐릭터(스킨)

기본으로 **우사기**(Usagi), **하치와레**(Hachiware), **치이카와**(Chiikawa), **랏코**(Rakko)와 **스프라우트**(Sprout, 직접 만든 마스코트)가 들어 있고, 트레이 메뉴의 **캐릭터(스킨)** 에서 고를 수 있어요. 목록은 이름 순서예요. 처음 설치하면 우사기로 시작해요.

### 스킨 만들기 (배경 지우기 포함)

트레이 메뉴의 **스킨 만들기…** 를 누르면 스킨 메이커가 열려요. 폴더나 JSON을 손으로 만들 필요 없이, 캐릭터 이미지만 있으면 돼요.

1. 이미지를 창에 끌어다 놓거나 **파일 선택…** 으로 불러와요. PNG · GIF · WebP · APNG · JPG, 움직이는 이미지도 돼요.
2. 이미지마다 **포즈**(기본·걷기·놀람·기쁨…)를 골라요. 파일 이름에 `idle`, `happy`, `sleep` 같은 말이 있으면 알아서 골라 줘요. **기본(idle)** 은 꼭 필요하고, 안 쓸 이미지는 "사용 안 함"으로 두세요. 없는 포즈는 비슷한 포즈로 대신해요.
3. 배경이 있는 이미지는 **배경 지우기**가 자동으로 켜져요. 테두리 색을 찾아 *바깥쪽* 배경만 지우기 때문에 몸 안의 같은 색(하얀 배 같은)은 남아요. 덜 지워지거나 몸까지 지워지면 *허용 오차*를, 하얀 테두리가 남으면 *가장자리 깎기*를 조절하세요. 원본 이미지를 클릭해서 지울 색을 직접 고를 수도 있어요. 이미 투명한 이미지는 그대로 써요.
4. 같은 그림인데 크기가 다른 이미지(작은 GIF와 큰 PNG 등)는 자동으로 크기를 맞춰요. 포즈마다 크기가 다르면 *크기*를, 다른 이미지와 반대쪽을 보고 있으면 *좌우 반전*을 쓰세요. 맨 위의 *원본이 바라보는 방향*은 대부분의 이미지가 보는 쪽이에요(펫이 반대로 걸을 때 뒤집는 데 써요).
5. 정지 이미지는 **움직임 넣기**에서 고르면 움직여요. 기본 자세에는 "눈 깜빡이고 귀 까딱", 걷기에는 "귀와 꼬리가 흔들", 달리기에는 "귀가 뒤로 날려요", 잠자기에는 "눈 감고 가끔 귀 움찔"을 쓰면 돼요. 그림에서 눈·귀·꼬리를 찾아 움직이기 때문에 못 찾으면 안내가 나오고 그림은 그대로 써요. 걷기와 기본 자세에 같은 그림을 쓰고 싶으면 같은 파일을 두 번 불러오세요.
6. 오른쪽 **펫 미리보기**에서 마우스를 올리고, 클릭하고, 끌어 보면서 확인한 뒤 **스킨 저장** → **지금 이 스킨 쓰기**를 누르면 끝이에요.

저장한 스킨은 `%APPDATA%\desktop-buddy\skins\<폴더 이름>` 에 만들어지고 앱을 업데이트해도 남아요. 같은 폴더 이름으로 다시 저장하면 덮어써요. 메이커는 `"Desktop Buddy.exe" --maker` 로 실행해도 바로 열려요.

### 스킨 폴더를 직접 만들기

스킨은 이미지 파일과 `manifest.json`이 들어 있는 폴더예요. 트레이 메뉴의 **스킨 폴더 열기**로 폴더를 열고(보통 `%APPDATA%\desktop-buddy\skins`), 그 안에 스킨마다 폴더를 하나씩 만드세요.

```
skins/
  my-skin/
    manifest.json
    idle.png        ← 필수
    happy.gif       ← 선택
```

```json
{
  "name": "My skin",
  "names": { "ko": "내 스킨" },
  "size": { "w": 128, "h": 128 },
  "anchor": { "x": 0.5, "y": 0.94 },
  "hitbox": { "x": 0.17, "y": 0.1, "w": 0.66, "h": 0.81 },
  "facing": "right",
  "poses": { "idle": "idle.png", "happy": "happy.gif", "sleep": "sleep.png" }
}
```

- `name`은 메뉴에 보이는 이름이에요. 한국어 이름을 따로 보이고 싶으면 `names`의 `ko`에 적으세요(한국어 Windows에서만 쓰이고, 없으면 `name`을 써요).
- **포즈**: `idle`(필수), `walk`, `run`, `sit`, `sleep`, `held`(들렸을 때), `fall`, `land`, `surprised`, `happy`. 없는 포즈는 비슷한 포즈로, 최종적으로 `idle`로 대체돼요. 걷기·앉기 같은 동작은 정지 이미지만 있어도 코드로 통통 튀고 찌그러지며 움직여요.
- **파일 형식**: `png`, `apng`, `gif`, `webp`, `svg`. 움직이는 GIF/APNG/WebP도 그대로 재생돼요. GIF는 투명도가 1비트라 가장자리가 거칠 수 있어서 **투명 배경 PNG(또는 APNG/WebP)** 를 권장해요.
- `size`는 스프라이트 상자의 크기(px), `anchor`는 발 위치, `hitbox`는 몸통 영역(클릭과 화면 가장자리 제한에 쓰여요)이고 모두 상자 대비 비율이에요. 이미지는 상자 안에 비율을 유지한 채 아래쪽 가운데로 맞춰져요.
- `facing`은 그림이 기본으로 바라보는 방향(`"left"` / `"right"`)이에요. 펫이 반대쪽으로 걸을 때 그림을 좌우로 뒤집어요.
- **스프라이트 시트**(스킨 메이커가 GIF를 이 형식으로 바꿔 줘요): 프레임을 왼쪽에서 오른쪽, 위에서 아래로 늘어놓은 PNG 한 장이에요. `durations`는 프레임당 ms(숫자 하나, 또는 프레임마다 배열)예요.
  ```json
  "happy": { "sheet": "happy.png", "frameWidth": 239, "frameHeight": 243, "count": 13, "durations": 100 }
  ```
- `"motion": { "happy": "off" }` — 그림 자체가 움직이는 포즈는 엔진의 통통 튀기·찌그러짐을 꺼요.
- `"states": { "fall": "surprised" }` — 어떤 상황에 어떤 포즈를 쓸지 직접 정해요.
- **대사**(선택): `lines`에 상황별로 말을 넣으면 펫이 말해요. 글자는 말풍선 없이 z나 하트처럼 그려져요. 짧은 소리(`"야하!"`)는 위로 떠오르며 사라지고, 문장(`"오늘도 어떻게든 돼!"`)은 머리 위에 잠깐 떠 있다 사라져요. 띄어쓰기 없이 짧은 줄은 소리로, 그 밖은 문장으로 나뉘고, `{ "text": "...", "style": "float" | "hold" }` 로 직접 정할 수 있어요. 글자 색은 `textColor`(`#rrggbb`)예요.
  ```json
  "textColor": "#c77a14",
  "lines": {
    "click": ["하아? 하아?", "하아!?"],
    "cross": ["우-라-", { "text": "다른 모니터다!", "style": "hold" }]
  }
  ```
  상황은 `start`(처음 나타날 때, 스킨을 바꿨을 때), `hover`(마우스가 닿을 때), `click`, `rub`(쓰다듬기), `triple`(세 번 클릭), `pickup`(들어 올림), `throw`(던짐), `land`(높은 데서 착지), `flee`(도망), `follow`(마우스를 따라갈 때), `attach`(마우스에 매달릴 때), `idle`(혼잣말), `sit`, `sleep`, `wake`, `cross`(다른 모니터로 건너갈 때), `call`(불렀을 때), `welcome`(자리로 돌아왔을 때: 잠금 해제·절전 복귀), `plug`·`unplug`(충전기를 꽂을 때·뺄 때), `lowBattery`(배터리 부족), `meet`(친구를 만나 먼저 하는 인사), `reply`(친구의 인사에 하는 대답)예요. 한 상황에 줄을 여러 개 넣으면 돌아가며 말해요(같은 줄이 연달아 나오지 않아요). 상황마다 16줄, 한 줄은 40자까지예요.
  `meet`와 `reply`의 줄에는 `"with"`로 스킨 폴더 이름을 적어서 그 친구에게만 하는 말로 만들 수 있어요: `{ "text": "랏코 씨~! 안녕하세요!", "with": ["rakko"] }`. 그 친구를 위한 줄이 있으면 그 줄만 쓰고, 없으면 `with`가 없는 줄을 쓰니까 처음 보는 친구를 위해 `with` 없는 줄도 몇 개 넣어 두세요.
- **재롱**(선택): `actions`에 적으면 펫이 가끔 그 그림으로 짧은 행동을 해요. 그림은 `poses`에 다른 포즈처럼 넣어요(없는 그림을 가리키는 재롱은 무시돼요).
  ```json
  "poses": { "idle": "idle.png", "camera": "camera.png", "cheer": { "sheet": "cheer.png", "frameWidth": 305, "frameHeight": 323, "count": 8, "durations": 80 } },
  "actions": {
    "camera": { "pose": "camera", "ms": 3600, "motion": "still", "say": ["찰칵!", "자, 치즈~!"] },
    "cheer": { "pose": "cheer", "ms": 2400, "on": ["welcome", "plug"], "say": ["신난다~!"] }
  }
  ```
  `pose`는 쓸 포즈(이름을 생략하면 재롱 이름)이고, `ms`는 얼마나 하는지(0.8~20초, 기본 2.6초)예요. `weight`는 뽑힐 확률의 비율(기본 1)이에요. `motion`은 엔진이 그림을 어떻게 움직일지로 `bounce`(통통 튐), `sway`(좌우로 흔들), `still`(숨만 쉼), `off`(그림 자체가 움직이니 가만히 둠)이고, 정지 이미지는 `bounce`, 움직이는 스프라이트 시트는 `off`가 기본이에요. `on`은 일반 반응 대신 이 재롱을 하는 상황(`welcome`, `plug`, `unplug`, `lowBattery`, `call`)이고, 그때는 그 상황의 대사를 하고 `say`는 말하지 않아요. `say`는 스스로 시작할 때 하는 말이에요. 같은 재롱이 연달아 나오지 않아요. 상태에 쓰는 포즈를 재롱에 다시 써도 돼요(우사기의 응원 도구는 착지 포즈예요). 스킨 메이커에서는 이미지의 포즈를 **재롱 1~4**로 고르면 알아서 `actions`가 만들어져요.
- **저작권**: 우사기·하치와레·치이카와·랏코 이미지는 ちいかわ(© ナガノ)의 저작물이고, 저장소 소유자가 개인·지인용으로 제공해서 `skins/usagi`, `skins/hachiware`, `skins/chiikawa`, `skins/rakko`에 들어 있어요. 이 저장소의 라이선스 대상이 아니며 권리자의 요청이 있으면 삭제해요(각 폴더의 `NOTICE.txt`). 스킨을 만들 때는 이미지의 사용 권한을 확인해 주세요.

## 문제가 생기면

- **로그**: `%APPDATA%\desktop-buddy\buddy.log`
- **클릭 통과가 이상할 때**: 환경 변수 `BUDDY_DEBUG=1`로 실행하면 클릭 통과가 바뀔 때마다 로그에 남아요.
- **펫이 안 보여요**: 트레이 아이콘이 있는지 확인하세요. 모니터가 여러 대면 트레이 메뉴의 **모니터**가 '주 모니터만'이나 다른 모니터로 되어 있는지 보세요. 로그의 `screens:` 줄에 펫이 올라간 모니터가 남아요.
- **백신이 막아요**: 코드 서명이 없어서 생기는 오탐일 수 있어요. 소스는 이 저장소에 그대로 공개돼 있어요.

## 개발

Node.js 22 이상이 필요해요.

```bash
npm install
npm run dev:web     # 브라우저 테스트 페이지 (http://localhost:5173), 스킨 메이커는 /maker.html (저장하면 ./skins/<이름>)
npm start           # Electron으로 실행 (빌드 후)
npm test            # 단위 테스트
npm run typecheck
npm run dist        # Windows 설치 파일 (Windows에서 실행)
```

브라우저 테스트 페이지에서는 마우스가 곧 커서예요. 주소 뒤에 `?debug=1`(히트박스 표시), `?mode=wander`, `?sleepAfter=1500`(빨리 졸게), `?chatty=1`(모든 상황에서 자주 말하게) 같은 옵션을 붙일 수 있어요.

모니터가 한 대뿐인 PC에서 멀티 모니터를 시험하려면 가짜 모니터를 줄 수 있어요(설치된 앱에서는 무시돼요). 예: `BUDDY_FAKE_DISPLAYS='[{"id":1,"x":0,"y":0,"width":1280,"height":720,"primary":true},{"id":2,"x":1280,"y":0,"width":1024,"height":600}]' npm start`. 화면이 가짜 모니터를 다 덮을 만큼 커야 보여요. 이 값에 `BUDDY_TEST=1`을 더하면 자동 시험이 쓰는 `globalThis.__buddyTest`도 생겨요.

```
src/engine/     순수 TypeScript 엔진: 상태머신, 물리, 모드, 상호작용 (DOM/Electron 의존 없음, 테스트됨)
src/renderer/   Canvas 렌더러(메인이 보낸 펫을 그리기만 함), 스킨 로더, 브라우저 테스트 페이지(여기서는 엔진을 직접 돌림)
src/shell/      Electron 메인: 펫 시뮬레이션(stage, 여러 마리), 모니터별 투명 오버레이 창, 클릭 통과, 트레이, buddy:// 프로토콜, 설정
src/maker/      스킨 메이커의 이미지 처리: 배경 제거, 트리밍, 정렬, 스프라이트 시트, 정지 그림 움직임 만들기 (순수 TypeScript, 테스트됨)
src/shared/     메인과 렌더러가 공유하는 타입, 스킨 manifest 검증
skins/default/  기본 마스코트 Sprout
skins/usagi/ hachiware/ chiikawa/ rakko/    ちいかわ 캐릭터 스킨 (저작권은 권리자에게 있음)
CHANGELOG.md    버전마다 바뀐 점 (릴리스 설명과 업데이트 알림에 쓰여요)
scripts/        빌드와 릴리스에 쓰는 스크립트
docs/PLAN.md    기획과 로드맵
```

**릴리스**: 먼저 [CHANGELOG.md](CHANGELOG.md)에 새 버전의 `## 0.3.2` 항목을 적고(사용자가 알아챌 변경을 한 줄씩, `- 요약 — 자세한 설명` 형식), `package.json`의 `version`을 올려 커밋해요. 그다음 `git tag v0.3.2 && git push origin v0.3.2` 을 하면 GitHub Actions가 설치 파일, 포터블 zip, 그리고 설치된 앱이 업데이트에 쓰는 `latest.yml`과 `.blockmap`을 만들어 Release에 올려요. 릴리스 설명에는 CHANGELOG의 그 버전 항목이 그대로 들어가고, 앱은 업데이트 뒤 처음 켤 때 같은 내용을 알림으로 보여줘요. 태그를 올릴 수 없으면 Actions 탭에서 build 워크플로를 `Run workflow`로 실행하면서 `release_tag`에 `v0.3.2`를 적어도 돼요. 태그와 `package.json`의 버전이 다르거나 CHANGELOG에 그 버전 항목이 없으면 워크플로가 릴리스를 멈춰요(버전이 다르면 설치된 앱이 업데이트를 못 받거나 계속 받으려 해요).
