# Desktop Buddy

바탕화면을 돌아다니고, 마우스에 붙어 다니고, 마우스에 반응하는 **Windows 데스크탑 펫**입니다.
(Desktop Buddy는 가칭입니다. A tiny desktop pet for Windows that wanders the screen, sticks to your mouse and reacts to it.)

## 다운로드와 설치 (Windows 10 / 11, 64비트)

1. 위의 **설치 파일(.exe)** 버튼을 눌러 받습니다. 설치가 싫으면 **포터블 zip**을 받아서 풀고 `Desktop Buddy.exe`를 실행하면 됩니다.
2. 설치 파일을 실행하면 바로 설치되고 시작됩니다.
3. 처음 실행할 때 Windows가 "PC를 보호했습니다" 화면을 띄울 수 있습니다. 코드 서명을 하지 않은 앱이라서 그렇습니다. **추가 정보**를 누른 뒤 **실행**을 누르면 됩니다.
4. 펫은 주 모니터에서 시작하고, 작업 표시줄 오른쪽 아래(숨겨진 아이콘 `^` 안에 있을 수 있습니다)에 트레이 아이콘이 생깁니다.

버튼이 열리지 않거나 릴리스보다 새 빌드를 받고 싶으면 [Actions](https://github.com/catdevdog/chiikawa/actions/workflows/build.yml)에서 초록 체크가 붙은 맨 위 항목을 열고, 맨 아래 **Artifacts**의 `windows`를 받으면 됩니다. zip 안에 설치 파일과 포터블 zip이 들어 있습니다. GitHub 로그인이 필요하고 90일 뒤에 지워집니다.

## 기능

- **돌아다니기와 마우스 반응**: 투명한 창 위에서 화면을 돌아다니고, 마우스를 따라오거나 마우스에 붙어 다닙니다. 마우스를 올리고, 클릭하고, 쓰다듬고, 끌어서 던질 수 있습니다. 펫이 없는 곳은 클릭이 그대로 통과합니다.
- **캐릭터(스킨)**: 우사기, 하치와레, 치이카와, 랏코와 직접 만든 마스코트 스프라우트가 들어 있고, 트레이 메뉴에서 고릅니다. 처음 설치하면 우사기로 시작합니다.
- **스킨 메이커**: 이미지를 끌어다 놓고 포즈만 고르면 내 스킨이 만들어집니다. 배경 지우기와 움직임 넣기도 됩니다.
- **대사**: 상황마다 한마디씩 합니다. 말풍선 없이 글자가 떠올랐다가 사라지고, 트레이 메뉴에서 줄이거나 끌 수 있습니다.
- **재롱**: 캐릭터마다 가끔 특별한 행동을 하고, 트레이 메뉴에서 바로 시킬 수도 있습니다.
- **친구들**: 다른 캐릭터와 함께 지낼 수 있고(주인공까지 최대 다섯 마리), 가까이 만나면 서로 인사합니다.
- **숨바꼭질**: 펫을 빠르게 세 번 클릭하면 나와 있는 캐릭터가 모두 가까운 벽으로 달려가 얼굴을 내밀고 숨습니다.
- **열린 창과 어울리기**: 다른 프로그램의 창 위에 앉고, 윗변에 매달리고, 창 옆에 숨습니다. Windows에서만 보이고 기본은 켜져 있습니다.
- **관심 끌기(실험 기능)**: 오래 놀아 주지 않으면 마우스 커서를 끌고 갑니다. Windows에서만 보이고 기본은 꺼져 있습니다.
- **펫 부르기와 숨기기**: 어느 프로그램을 쓰고 있어도 단축키로 펫을 부르거나 잠깐 숨깁니다.
- **컴퓨터 상태에 반응**: 화면 잠금을 풀거나 절전에서 깨어날 때, 충전기를 꽂고 뺄 때, 배터리가 모자랄 때 반응합니다.
- **여러 모니터**: 모니터가 여러 대이면 모니터 사이를 걸어 다닙니다.
- **자동 업데이트**: 설치 파일로 설치한 앱은 새 버전을 스스로 받아 두고, 업데이트한 뒤 처음 켜면 바뀐 점을 알려 줍니다.
- **트레이 메뉴**: 크기, 이동 범위, 모니터, 대사, 캐릭터, 친구들, 시작 시 실행 같은 설정을 바꿉니다.

기능의 자세한 설명과 사용법은 [사용법](docs/GUIDE.md)에, 스킨 만드는 방법은 [스킨 문서](docs/SKINS.md)에, 개발과 릴리스는 [개발 문서](docs/DEVELOPMENT.md)에 있습니다. 아직 확인하지 못한 것은 [사용법의 아직 안 된 것](docs/GUIDE.md#아직-안-된-것)에 적어 두었습니다.
