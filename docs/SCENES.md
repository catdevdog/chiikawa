# 장면

장면은 소리와 함께 바탕화면 위에서 보여 주는 짧은 공연입니다. 장면에 나오는 캐릭터(출연자)의 펫은 장면이 도는 동안 화면에서 빠졌다가, 끝나면 있던 자리로 돌아옵니다. 그림은 투명한 영상이나 이미지이고, 소리는 따로 둔 파일이거나 영상에 든 소리입니다.

앱에는 장면이 들어 있지 않습니다. 장면은 이 PC의 폴더에서만 읽고, 저장소와 설치 파일에는 넣지 않습니다. 직접 만들었거나 쓸 권리가 있는 그림과 소리로 만들기를 권합니다.

## 시작하기

1. 트레이 메뉴의 **장면 보기**에서 **장면 폴더 열기**를 누릅니다(보통 `%APPDATA%\desktop-buddy\scenes`입니다).
2. 장면마다 폴더를 하나 만들고, 그 안에 `scene.json`과 그림과 소리 파일을 넣습니다.
3. 트레이 메뉴의 **장면 보기**에 장면 이름이 나타납니다. 누르면 시작하고, 시작한 장면은 **장면 멈추기**나 그림을 클릭해서 끝낼 수 있습니다.

```
scenes/
  my-scene/
    scene.json
    scene.webm      (그림: 투명도가 있는 영상)
    song.mp3        (소리: 선택)
```

## scene.json

```json
{
  "name": "My scene",
  "names": { "ko": "내 장면" },
  "video": "scene.webm",
  "audio": "song.mp3",
  "size": { "w": 640, "h": 360 },
  "anchor": { "x": 0.5, "y": 0.95 },
  "cast": ["hachiware", "chiikawa"]
}
```

그림은 `video`(투명도가 있는 WebM 영상)이거나 `picture`(스킨의 포즈처럼 이미지 파일 하나, 또는 스프라이트 시트)입니다. 둘 다 있으면 `video`를 씁니다. 나머지는 모두 선택입니다.

```json
"picture": { "sheet": "scene.png", "frameWidth": 320, "frameHeight": 180, "count": 48, "durations": 50 }
```

- `name`은 메뉴에 보이는 이름이고, `names`의 `ko`에 한국어 이름을 따로 적을 수 있습니다.
- `video`는 영상 파일입니다. 투명도는 알파가 있는 WebM(VP9)일 때만 살아 있고, 다른 영상은 배경까지 그대로 나옵니다. 영상에 든 소리는 `audio`가 없을 때 그대로 납니다.
- `picture`는 이미지 파일(png, apng, gif, webp)이나 스프라이트 시트입니다. 움직이는 이미지와 시트는 각 프레임의 길이대로 재생되고, 움직이지 않는 그림은 소리가 끝날 때까지 그대로 있습니다. 소리가 없는 움직이지 않는 그림은 클릭하거나 `maxMs`가 지나야 끝납니다.
- `audio`는 소리 파일입니다(mp3, ogg, wav, m4a, opus, flac). 없으면 영상은 자기 소리를 내고, `picture`는 소리가 없습니다.
- `size`는 보통 크기에서 그림이 차지하는 칸의 크기(px)입니다. 그림은 이 칸 안에 비율을 지킨 채 아래쪽 가운데로 맞춰지고, 펫 크기 설정을 따라 커지고 작아집니다. 생략하면 640 x 360입니다.
- `anchor`는 그림 속 발 위치로, 칸에 대한 비율입니다. 그림은 이 점이 펫의 발 위치에 오도록 놓입니다. 생략하면 가운데 아래(0.5, 0.95)입니다.
- `hitbox`는 클릭하면 장면이 끝나는 부분으로, 칸에 대한 비율입니다. 생략하면 칸의 가운데 큰 부분입니다.
- `cast`는 출연하는 캐릭터의 스킨 폴더 이름입니다. 이 캐릭터의 펫이 화면에 있으면 장면이 시작될 때 빠졌다가 끝나면 돌아옵니다. 없는 캐릭터는 무시하고, 비워 두면 아무도 빠지지 않습니다.
- `offsetMs`는 소리가 그림보다 몇 ms 늦게 시작하는지입니다(음수면 먼저 시작합니다). 생략하면 0입니다.
- `volume`은 이 장면의 소리 크기로 0에서 1까지입니다. 트레이의 **장면 소리**와 곱해집니다. 생략하면 1입니다.
- `maxMs`는 장면이 가장 길게 이어질 수 있는 시간(ms)입니다. 이 시간이 지나도 끝나지 않으면 앱이 끝냅니다. 생략하면 10분입니다.

## 재생되는 방식

- 장면은 `cast`의 펫이 있는 자리에 놓입니다. 출연자가 화면에 없거나 `cast`가 비어 있으면 주인공의 자리에 놓입니다. 펫이 들려 있거나 숨어 있거나 마우스에 붙어 있으면 시작하지 않습니다.
- 그림과 소리가 준비되면 출연자의 펫이 화면에서 빠지고 장면이 시작됩니다. 준비되지 못하면(파일이 깨졌거나 8초가 넘게 걸리면) 아무 일도 없었던 것처럼 펫이 그대로 있고, `buddy.log`에 이유가 남습니다.
- 소리가 시계입니다. 영상과 소리를 따로 둘 때는 매 프레임 영상을 소리가 있는 곳에 맞추고, 어긋나면 영상을 조금 빠르게 또는 느리게 틀어서, 많이 어긋나면 그 자리로 옮겨서 바로잡습니다. 시트와 움직이는 이미지는 소리의 시간으로 프레임을 고릅니다.
- 장면은 한 모니터 안에서 보이고, 한 번에 하나만 돕니다. 장면이 도는 동안 펫을 불러도, 숨겨도, 세 번 클릭해서 숨바꼭질을 시작해도, 모니터가 바뀌어도 장면이 끝나고 출연자가 돌아옵니다.
- 그림 위의 `hitbox` 부분을 클릭하면 장면이 끝납니다. 그 밖은 클릭이 그대로 아래 창으로 통과합니다.
- 소리 크기는 트레이 메뉴의 **장면 보기**, **장면 소리**에서 끄기, 작게, 보통, 크게 중에서 고릅니다. 장면이 도는 중에도 바꿀 수 있습니다.

## 그림 준비

- 가장 좋은 형식은 알파가 있는 WebM(VP9)입니다. 파일이 작고 가장자리가 부드러우며, 소리를 같이 넣을 수도 있습니다. 투명한 PNG 프레임 묶음에서는 이렇게 만들 수 있습니다.

  ```
  ffmpeg -framerate 24 -i frame_%04d.png -c:v libvpx-vp9 -pix_fmt yuva420p -auto-alt-ref 0 scene.webm
  ```

- GIF는 투명도가 1비트라 가장자리가 거칠고 색도 256색으로 줄어듭니다. 투명한 APNG나 WebP, 또는 스프라이트 시트를 권합니다. 스킨 메이커가 GIF를 시트로 바꿔 주기는 하지만, 한 장 한 장이 메모리에 올라가므로 길이는 20초 안쪽으로 하는 것이 좋습니다.
- 그림이 소리와 다른 파일이면 둘을 같은 원본에서 뽑아야 맞습니다. 길이나 편곡이 다른 소리는 어긋날 수 있고, 그때는 `offsetMs`로 시작 위치를 맞춥니다.
- 화면이 큰 영상은 `size`를 실제 크기보다 작게 적어도 됩니다. 그림이 그 칸에 맞춰 줄어듭니다.

## 문제가 생기면

- 트레이 메뉴에 장면이 나타나지 않으면 `scene.json`이 올바른지, 거기 적은 파일이 폴더 안에 있는지 확인합니다. 문제가 있는 장면은 메뉴에서 빠지고, `%APPDATA%\desktop-buddy\buddy.log`의 `scenes:` 줄에 이유가 한 번 남습니다.
- 장면을 눌렀는데 아무 일도 없으면 같은 로그의 `scene <이름>` 줄을 봅니다. `cannot be shown now`는 펫이 들려 있거나 숨어 있거나 다른 장면이 도는 중이라는 뜻이고, `could not be played`는 영상이나 소리를 열지 못했다는 뜻입니다.
- 소리가 나지 않으면 트레이의 **장면 소리**가 **끄기**가 아닌지, `scene.json`의 `volume`이 0이 아닌지 확인합니다.
