# 사용법

처음 설치하는 방법은 [README](../README.md)에 있습니다. 이 문서에는 트레이 메뉴와 놀이 방법, 지금까지 만든 기능의 자세한 설명, 아직 확인하지 못한 것, 문제가 생겼을 때 볼 곳을 모았습니다. 스킨은 [스킨 문서](SKINS.md)에, 개발은 [개발 문서](DEVELOPMENT.md)에 있습니다.

## 트레이 메뉴

트레이 아이콘을 클릭(또는 우클릭)하면 메뉴가 열립니다.

| 메뉴 | 설명 |
|---|---|
| 펫 부르기 | 펫이 마우스 옆으로 와서 인사합니다. 자고 있어도, 숨어 있어도 옵니다. 단축키는 `Ctrl + Alt + Shift + C`입니다. |
| 잠깐 숨기기 | 펫을 치워 둡니다. 다시 누르면(**다시 나타나기**) 그 자리에서 돌아옵니다. 단축키는 `Ctrl + Alt + Shift + H`입니다. |
| 재롱 부리기 | 캐릭터가 재롱을 하나 보여 줍니다. 재롱이 있는 캐릭터에서만 보이고, 펫이 숨어 있을 때는 누를 수 없습니다. |
| 모드 | **자동**은 마우스가 움직이면 따라오고, 멈추면 돌아다니다 졸습니다. 그 밖에 **따라가기**, **마우스에 붙어있기**, **배회**가 있습니다. |
| 크기 | 작게, 보통, 크게, 아주 크게 중에서 고릅니다. |
| 이동 범위 | **화면 전체** 또는 **바닥만**을 고릅니다. |
| 모니터 | **모든 모니터**(기본), **주 모니터만**, 모니터 하나 고르기가 있습니다. 모니터가 한 대이면 이 메뉴는 보이지 않습니다. |
| 대사 | **반응과 혼잣말**(기본), **반응할 때만**, **끄기** 중에서 고릅니다. |
| 캐릭터(스킨) | 설치된 스킨을 고릅니다. **스킨 폴더 열기**도 여기에 있습니다. |
| 친구들 | 함께 지낼 다른 캐릭터를 고릅니다. 체크하면 바로 나타나고, 빼면 사라집니다. 최대 4명까지이고, 고를 다른 캐릭터가 없으면 이 메뉴는 보이지 않습니다. |
| 스킨 만들기 | 이미지로 직접 스킨을 만드는 **스킨 메이커**를 엽니다(배경 지우기를 포함하며, [스킨 문서](SKINS.md)에 설명이 있습니다). |
| 방해하지 않기 | 켜면 펫이 클릭을 전혀 가로채지 않습니다(움직이기만 합니다). |
| 열린 창 위에 앉고 옆에 숨기 | 켜져 있으면 펫이 다른 프로그램의 창 윗변에 올라가 앉고, 가끔 윗변에 매달리고, 끌어다 창 옆에 놓으면 그 옆에 숨습니다. 기본은 켜짐이고 Windows에서만 보입니다. |
| 오래 안 놀아 주면 관심 끌기 (실험 기능) | 켜면 오래 가만히 둔 펫이 마우스 커서 곁으로 달려와 기다리다가, 마우스가 멈춰 있으면 커서를 붙잡고 끌고 갑니다. 마우스를 움직이면 놓아 줍니다. 기본은 꺼짐이고 Windows에서만 보입니다. |
| Windows 시작 시 실행 | 설치 버전에서 동작합니다. |
| 업데이트 자동 확인 | 설치 버전에서만 보입니다. 끄면 백그라운드 확인과 다운로드를 멈춥니다(아래의 **업데이트 확인**은 그대로 쓸 수 있습니다). |
| 업데이트 확인 | 지금 새 버전을 찾습니다. 찾으면 받아 두고, 다 받으면 **vX 설치하고 다시 시작**으로 바뀝니다. 포터블 zip에서는 릴리스 페이지를 엽니다. |
| 바뀐 점 보기 | 지금 버전에서 무엇이 바뀌었는지 릴리스 페이지를 엽니다. |
| 종료 | 비상 종료 단축키는 `Ctrl + Alt + Shift + B`입니다. 받아 둔 업데이트가 있으면 종료할 때 설치됩니다. |

## 펫과 놀기

- 마우스를 올리면 걸음을 멈추고 쳐다봅니다. 좌우로 문지르면(쓰다듬기) 좋아합니다.
- 클릭하면 깜짝 놀랍니다. 빠르게 3번 클릭하면 모두 벽으로 가서 숨습니다(아래에 설명이 있습니다).
- 잡아서 끌면 들려서 대롱대롱 매달리고, 놓으면 떨어집니다. 휙 던질 수도 있습니다.
- 마우스를 빠르게 휘둘러 다가가면 놀라서 도망갑니다(배회 중일 때).
- 아무도 건드리지 않으면 졸다가 잠듭니다.
- `Ctrl + Alt + Shift + C`(또는 메뉴의 **펫 부르기**)로 부르면 어디에 있든 마우스 옆으로 옵니다. 가까우면 달려오고, 아주 멀거나 다른 모니터에 있으면 마우스 위에서 떨어집니다.
- 자리로 돌아오면(화면 잠금 해제, 절전에서 깨어남) 반기고, 충전기를 꽂고 뺄 때나 배터리가 얼마 남지 않았을 때도 한마디 합니다.
- 창 위에 앉는 기능이 켜져 있으면(기본) 펫이 가끔 다른 프로그램의 창 위로 올라갑니다. 앉은 펫도 평소처럼 잡아서 옮기거나 던질 수 있고, 가끔 창 윗변에 매달려 입까지만 내밀고 쳐다보는데 클릭하면 올라옵니다. 펫을 끌어서 창의 왼쪽이나 오른쪽 가장자리 옆에 천천히 놓으면(휙 던지지 않고) 그 창 옆에 숨고, 클릭하거나 다시 끌어내면 나옵니다.
- 관심 끌기(실험 기능)를 켜 두고 오래 자리를 비우면 펫이 마우스 쪽으로 달려와 기다립니다. 마우스를 가만히 두면 커서를 끌고 가고, 마우스를 움직이면 바로 놓아 줍니다. 마우스 버튼을 누르고 있는 동안에는 건드리지 않습니다.
- **붙어있기** 모드에서는 펫이 마우스 커서에 매달려 따라옵니다. 이때 펫은 클릭을 가로채지 않아서 평소처럼 작업할 수 있습니다.
- 클릭, 쓰다듬기, 들어 올리기, 던지기, 잠들기와 깨기, 다른 모니터로 건너가기 같은 때에 한마디씩 합니다. 가만히 두면 가끔 혼잣말도 합니다.
- 가만히 돌아다니다가 가끔 재롱을 부립니다. 부리는 동안에는 제자리에 있고, 클릭하거나 잡으면 바로 멈춥니다. 자동 모드에서 마우스를 움직여 멀리 가면 재롱을 그만두고 따라옵니다.
- 숨바꼭질은 이렇게 합니다. 펫을 빠르게 3번 클릭하면 나와 있는 캐릭터가 모두 화면 양쪽 벽 가운데 클릭한 펫에서 가까운 쪽 벽으로 달려갑니다. 모니터가 여러 대이면 모든 모니터의 바깥쪽 가장자리가 벽입니다. 벽에 닿으면 하나씩 높이를 달리해서 벽 뒤로 숨고, 얼굴 일부와 손만 내밀고 기다립니다. 숨은 펫 가운데 하나를 클릭하거나 집어 올리면 모두 나옵니다. 마우스에 붙어있기 모드인 펫은 마우스에서 떨어지지 않습니다.
- 친구가 있으면 서로 가까이 만났을 때 먼저 다가간 쪽이 인사하고, 잠깐 뒤에 상대가 대답합니다. 같은 둘은 한동안 다시 인사하지 않습니다. 겹쳐 있으면 화면에서 더 아래에 있는(앞에 보이는) 펫이 클릭을 받고, 친구도 똑같이 쓰다듬고 들어 올리고 던질 수 있습니다. **마우스를 따라가거나 붙어 있는 것은 처음 고른 캐릭터뿐**이고 친구는 늘 배회합니다.

## 기능 자세히

- Windows 데스크탑 펫 앱(Electron)입니다. 투명한 창 위에 펫이 돌아다니고, 펫이 없는 곳은 클릭이 그대로 통과합니다.
- 모드는 자동, 따라가기, 마우스에 붙어있기, 배회의 4가지입니다. 마우스 반응으로는 올리기, 클릭, 세 번 클릭, 쓰다듬기, 드래그, 던지기, 도망, 졸기가 있습니다.
- 캐릭터는 우사기, 하치와레, 치이카와, 랏코와 스프라우트(직접 만든 마스코트)의 다섯 개입니다. 메뉴에는 한글 이름으로 보입니다. 처음 설치하면 우사기로 시작합니다. 눈을 깜빡이고, 잘 때는 눈을 감습니다. 귀와 꼬리가 있는 캐릭터는 걸을 때 흔들립니다.
- 스킨 메이커가 있습니다. 이미지를 끌어다 놓고 포즈만 고르면 스킨이 만들어집니다. 배경 지우기, 좌우 반전, 크기 맞추기, 미리보기를 할 수 있습니다.
- 정지 그림에 움직임을 넣을 수 있습니다. 그림에서 눈, 귀, 꼬리를 찾아 눈 깜빡임과 귀, 꼬리의 흔들림을 만듭니다. 그림을 새로 그리지 않고 원래 픽셀을 살짝 변형합니다.
- 모니터가 여러 대이면 펫이 모니터 사이를 걸어 다닙니다. 경계에 걸쳐 서 있으면 양쪽 모니터에 나뉘어 그려지고, 모니터마다 바닥 높이가 다르면(작업 표시줄이나 해상도 차이) 계단처럼 오르내립니다. 모니터를 뽑거나 꽂거나 해상도를 바꿔도 따라갑니다.
- 펫이 상황마다 한마디씩 합니다. 말풍선 없이 z나 하트처럼 그려져서, 짧은 소리는 위로 떠올랐다 사라지고 문장은 머리 위에 잠깐 떠 있다 사라집니다. 치이카와와 우사기는 소리로만 말하고, 하치와레와 랏코는 원작에서 한 말과 그 말투에 맞춘 대사를 합니다. 스프라우트는 앱의 오리지널 캐릭터라 직접 쓴 대사가 들어 있습니다.
- 자동 업데이트를 합니다. 설치 파일로 설치한 앱은 실행하고 30초 뒤, 그리고 6시간마다 새 버전이 있는지 확인하고, 있으면 백그라운드로 받아 둡니다. 다 받으면 알림이 뜨고 트레이 메뉴에 **vX 설치하고 다시 시작**이 생깁니다. 누르지 않아도 앱을 종료할 때 설치됩니다. 포터블 zip은 스스로 업데이트하지 못해서, 메뉴의 **새 버전 확인**이 릴리스 페이지를 열어 줍니다. 확인할 때 접속하는 곳은 github.com뿐이고, 지금 버전은 트레이 아이콘에 마우스를 올리면 보입니다.
- 캐릭터마다 가끔 특별한 행동(재롱)을 합니다. 하치와레는 사진을 찍고 손을 비비며 조르고, 치이카와는 빗자루질을 하고 잠옷 차림으로 하품하고, 우사기는 훌라춤을 추고 응원 도구를 흔들고, 스프라우트는 손을 흔들고 간식을 먹습니다. 트레이 메뉴의 **재롱 부리기**로 바로 볼 수 있고, 잠금 해제, 충전기, 배터리 부족 같은 때에는 그 상황에 맞는 재롱으로 반응합니다.
- 펫을 부르거나 잠깐 숨길 수 있습니다. 어느 프로그램을 쓰고 있어도 `Ctrl + Alt + Shift + C`로 부르면 마우스 옆으로 달려오고(아주 멀면 위에서 떨어집니다), `Ctrl + Alt + Shift + H`로 숨기고 다시 불러낼 수 있습니다. 숨겨진 동안은 움직이지도 클릭을 막지도 않습니다.
- 다른 캐릭터와 함께 지낼 수 있습니다. 트레이 메뉴의 **친구들**에서 다른 캐릭터를 고르면 됩니다(최대 4명이고, 주인공까지 모두 다섯 마리입니다). 친구는 마우스와 상관없이 혼자 돌아다니고, 가끔 다른 친구 곁으로 가서 서로 인사합니다. 치이카와, 하치와레, 우사기, 랏코는 서로에게 하는 말투가 따로 있습니다(예: 하치와레가 랏코를 만나면 "오늘도 토벌이에요?"). 서로 이름은 부르지 않습니다. 친구가 함께 있으면 캐릭터마다 달랐던 크기를 주인공에 맞춰 모두 같게 보이도록 합니다. 부르기, 숨기기, 컴퓨터 소식은 모두에게 똑같이 적용됩니다.
- 열린 창과 어울립니다(Windows에서만, 기본은 켜짐). 펫이 다른 프로그램 창의 윗변에 올라가 앉고, 가끔 윗변에 두 손을 얹고 입까지만 내밀어 쳐다봅니다. 이동 범위가 **바닥만**인 펫은 위로 뛰어올라 앉고, **화면 전체**인 펫은 걸어서 올라갑니다. 앉은 펫은 창 위를 거닐다가 가장자리에서 뛰어내리고, 창을 끌어 옮기면 같이 움직이고, 창이 닫히거나 최소화되면(바닥만인 펫은) 떨어집니다. 펫을 끌어다 창의 왼쪽이나 오른쪽 가장자리 옆에 놓으면 벽에 숨을 때처럼 그 창 옆에 숨어서 얼굴을 내밀고, 창을 옮기면 같이 움직입니다. 숨은 펫을 클릭하거나 끌어내리면 나옵니다. 앞에 있는 다른 창이 가린 윗변과 옆면에는 앉거나 숨지 않고, 위쪽이 화면에 닿는 창(최대화한 창)에는 앉을 자리가 없습니다. 창을 움직일 때 늦지 않게 따라가도록 펫이 앉았거나 숨은 창은 0.03초마다, 나머지 창은 0.2초마다 확인합니다.
- 오래 안 놀아 주면 관심을 끕니다(실험 기능이고 기본은 꺼짐, Windows에서만 보입니다). 트레이 메뉴의 **오래 안 놀아 주면 관심 끌기 (실험 기능)** 를 켜면, 10분 넘게 아무도 마우스를 올리거나 클릭하거나 부르지 않은 주인공이 가끔(할 일을 정할 때마다 15%의 확률로) 마우스 커서 곁으로 달려가서 소리를 냅니다(달리는 데는 15초까지 걸립니다). 마우스가 1.5초 동안 가만히 있으면 커서를 붙잡아 자기 등 뒤로 끌어당기고, 걸어서 멀리 갑니다(길어야 10초). 마우스를 움직이면 바로 놓아 주고 놀라거나 기뻐하며, 20분에서 40분은 다시 나서지 않습니다(마우스가 멈추기를 12초 기다려도 움직이면 포기하고 4분 뒤에 다시 나설 수 있습니다). 마우스 버튼이 눌려 있을 때, 전체 화면 앱이나 게임이나 발표가 화면을 쓰고 있을 때, 펫이 들려 있거나 숨어 있거나 졸고 있거나 창 위에 있을 때, 마우스에 붙어있기 모드일 때는 하지 않습니다. 펫이 하는 일은 커서를 옮기는 것뿐이고 클릭하거나 입력하지 않습니다. 친구는 하지 않습니다. 시스템 함수로 커서를 옮기므로 Windows에서만 되고, 다른 곳에서는 트레이 항목도 보이지 않습니다.
- 펫을 빠르게 세 번 클릭하면 나와 있는 캐릭터가 모두 화면의 가장 가까운 벽으로 달려가서 숨습니다. 얼굴을 벽 반대쪽으로 기울여 몸은 벽 뒤로 넘기고, 작은 손 두 개를 얼굴 윤곽의 위와 아래에 걸쳐 벽을 잡은 채 얼굴 일부를 내밀고 기다립니다. 가끔 벽 뒤로 쏙 들어갔다가 다시 나옵니다. 숨은 캐릭터를 다시 클릭하면 모두 나와서 하던 대로 돌아갑니다. 펫을 부르면(`Ctrl + Alt + Shift + C`) 숨어 있던 캐릭터도 마우스 옆으로 나옵니다.
- 컴퓨터 상태에 반응합니다. 화면 잠금을 풀거나 절전에서 깨어나면 반기고, 충전기를 꽂거나 빼면 알아채고, 배터리가 20% 아래로 떨어지면 알려 줍니다.
- 업데이트한 뒤 처음 켜면 무엇이 바뀌었는지 알림으로 알려 줍니다. 트레이 메뉴의 **바뀐 점 보기**에서 언제든 볼 수 있고, 전체 목록은 [CHANGELOG.md](../CHANGELOG.md)에 있습니다.
- 트레이 메뉴에서 크기, 이동 범위, 모니터, 대사, 캐릭터, 친구들, 클릭 통과, 시작 시 실행, 업데이트 자동 확인을 바꿀 수 있습니다.

## 아직 안 된 것

- 스킨 메이커와 우사기, 하치와레, 치이카와, 랏코 스킨은 Windows에서 아직 확인하지 못했습니다. 개발 환경이 Linux라서 이 부분은 Linux에서만 시험했습니다.
- 컴퓨터에 반응하는 기능(잠금 해제, 절전 복귀, 충전기, 배터리 부족)과 전역 단축키는 Linux에서 가짜 이벤트로만 시험했습니다. 실제 Windows에서는 아직 확인하지 못했습니다.
- 열린 창 위에 앉기, 윗변에 매달리기, 창 옆면에 숨기는 Linux에서 가짜 창 목록으로 시험했습니다. 실제 Windows 창을 읽는 부분(koffi로 시스템 함수를 부르는 코드)은 빌드할 때마다 Windows 러너에서 진짜 창으로 확인합니다(결과를 알려 줄 뿐 빌드를 막지는 않습니다). 메모장, 탐색기, 브라우저 같은 실제 프로그램의 창이 목록에 맞게 읽히고 최소화하면 목록에서 빠지는지 보고, 앱을 실제로 띄워서 마우스로 펫을 창 옆에 놓으면 숨는지, 창을 옮기면 따라가는지, 창을 최소화하거나 닫으면 펫이 놓고 떨어지는지를 배율 100%와 150%에서 봅니다. 사람이 쓰는 PC에서 앉고 매달리고 숨는 모습, 창을 끌어 옮길 때 따라가는 빠르기, 배율이 다른 모니터, 가상 데스크톱, 전체화면 앱은 아직 확인하지 못했습니다. 창을 최소화했는데도 숨은 펫이 그 자리에 매달려 있다는 보고가 있었지만 위의 확인에서는 재현하지 못했습니다. 다시 생기면 원인을 찾을 수 있도록 로그를 더 남기게 했습니다(아래 **문제가 생기면**에 있습니다). 정식 기능으로 올리면서 기본을 켜 두었고, 이상하면 트레이 메뉴에서 끌 수 있습니다.
- 관심 끌기(실험 기능)는 Linux에서 가짜 커서로 시험했고, 마우스 커서를 옮기고 마우스 버튼과 화면 상태를 읽는 시스템 함수가 진짜 Windows에서 되는지는 빌드할 때 확인합니다. 펫이 실제로 마우스를 끌고 가는 모습, 게임이나 전체 화면 앱이나 원격 데스크톱 위에서의 동작, 배율이 다른 모니터는 아직 확인하지 못했습니다. 기본이 꺼져 있는 까닭입니다.
- 숨기는 Linux에서만 시험했습니다. 실제 Windows에서 작업 표시줄이 옆에 있을 때와 배율이 다른 모니터에서 벽에 맞게 보이는지는 아직 확인하지 못했습니다.
- 친구들(여러 마리)도 Linux에서만 시험했습니다. 실제 Windows에서 다섯 마리가 함께 있을 때의 부하와 겹쳐 있을 때의 클릭은 아직 확인하지 못했습니다.
- 걷기는 따로 그린 그림이 아니라 기본 그림을 움직여서 만든 것입니다. 다리가 실제로 움직이는 걷기는 아닙니다. 그림이 없는 포즈(예: 치이카와의 달리기와 앉기)는 비슷한 포즈의 그림을 대신 씁니다.
- 멀티 모니터는 Linux에서 가짜 모니터로만 시험했습니다. 실제 Windows 모니터, 특히 배율이 서로 다른 모니터(예: 100%와 150%) 사이는 아직 확인하지 못했습니다.
- 대사는 한국어뿐입니다. 스킨 메이커에서 대사를 넣는 기능은 아직 없어서 manifest.json에 직접 적어야 합니다.
- 설정창과 소리는 아직 없습니다.
- 전체화면 앱 위에서 숨기는 기능이 없습니다.
- 자동 업데이트는 Windows에서 0.3.2를 설치한 앱이 0.4.0으로 업데이트되는 것까지 확인했습니다. 업데이트 기능이 들어가기 전의 버전(0.3.0 이하)을 쓰고 있다면 0.3.1 이상을 한 번 직접 설치해야 합니다.
- 코드 서명이 없어서 처음 실행할 때 Windows 경고가 뜹니다. 업데이트 파일도 서명이 아니라 GitHub 릴리스에 적힌 체크섬으로만 확인합니다.
- 만드는 것은 Windows용뿐입니다. macOS와 Linux용 빌드는 없습니다.

## 문제가 생기면

- **로그**는 `%APPDATA%\desktop-buddy\buddy.log`에 있습니다.
- **클릭 통과가 이상할 때**는 환경 변수 `BUDDY_DEBUG=1`로 실행하면 클릭 통과가 바뀔 때마다 로그에 남습니다.
- **펫이 보이지 않을 때**는 트레이 아이콘이 있는지 확인합니다. 모니터가 여러 대이면 트레이 메뉴의 **모니터**가 '주 모니터만'이나 다른 모니터로 되어 있는지 봅니다. 로그의 `screens:` 줄에 펫이 올라간 모니터가 남습니다.
- **창 위에 앉기가 되지 않을 때**는 Windows에서 트레이에 항목이 보이는지 확인합니다. 보이지 않으면 `buddy.log`에 `windows to sit on are not available`가 남았는지 봅니다(시스템 함수를 부르는 koffi를 불러오지 못한 것입니다). `could not read the windows`가 남았다면 창 목록을 읽다 오류가 난 것이라 그 실행 동안은 꺼집니다.
- **창을 최소화했는데 숨은 펫이 매달려 있을 때**는 `buddy.log`를 알려 주세요. 펫이 창 옆에 숨을 때는 `hides at the side of the window`, 놓을 때는 `let go of the window` 줄이 남고, 창이 어떤 종류의 프로그램인지(괄호 안의 클래스 이름)와 그때 창이 목록에 있었는지(`window listed: yes`나 `no`)도 적힙니다. 창이 읽히지 않게 되어 목록에서 뺄 때는 `is not listed any more` 줄이 남습니다. 숨은 뒤로 아무 줄도 남지 않았다면 앱은 그 창이 아직 있다고 보고 있는 것입니다. 펫의 그림만 멈춰 보였다면 `this window has not been painting for` 줄(창이 2초 넘게 그려지지 않았을 때)이나 `the simulation was held up for` 줄(펫을 움직이는 쪽이 2초 넘게 멈췄을 때)이 남았는지도 봅니다.
- **백신이 막을 때**는 코드 서명이 없어서 생기는 오탐일 수 있습니다. 소스는 이 저장소에 그대로 공개되어 있습니다.
